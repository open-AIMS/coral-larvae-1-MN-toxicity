*R Code for Data Processing and Analysis for the manuscript 'Molecular responses to 1-methylnaphthalene in Acropora millepora larvae'*

This repository contains scripts for processing gene expression data from coral larvae that have been exposed to 1 methylnaphthalene (1-MN) for 48-h, as well as a script for deriving settlement and gene-specific no-significant-effect-concentration threshold values. Scripts provided in this repository have been created using vignettes from the following R packages: DESeq2, DRomics, bayesnec and ssdtools.
